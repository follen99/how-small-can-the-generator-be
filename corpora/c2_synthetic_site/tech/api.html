📚 API Documentation

Base URL: https://api.technova.ai/v1

Autenticazione

Tutte le richieste richiedono un header Authorization: Bearer <token>

POST /chat

Invia una query al chatbot RAG

{
  "query": "Quali servizi offrite?",
  "session_id": "optional-session-id",
  "context_filter": {"source": "website"}
}

Response:

{
  "answer": "Offriamo consulenza AI, sviluppo chatbot e automazione RPA...",
  "sources": [
    {"url": "https://...", "title": "Servizi", "score": 0.95}
  ],
  "tokens_used": 342
}

POST /documents/upload

Carica documenti per indicizzazione

Content-Type: multipart/form-data

file: <binary>
metadata: {"client_id": "123", "project": "RAG"}

GET /documents/{id}

Recupera informazioni su un documento indicizzato

Rate Limiting

  • Free tier: 100 richieste/ora
  • Pro tier: 10,000 richieste/ora
  • Enterprise: illimitato

SDK Ufficiali

  • Python: pip install technova-sdk
  • JavaScript/TypeScript: npm install @technova/sdk
  • Go: go get github.com/technova/sdk-go
