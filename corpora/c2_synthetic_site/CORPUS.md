# C2 — synthetic site

A website built for this research, describing a **fictional** company ("TechNova"): eight HTML
pages with dynamic elements (accordions, tabs, lazy loading, tables, modals) and eight one-page
PDF documents. Every person, company and figure in it is invented. Its content is known
exactly, which is why it was chosen as a corpus.

Copied from RAG-Maker, commit `21d9181`, folder `tests/website/` (the `tests/` subfolder with
an unrelated question list is omitted). `README.md` is the original description in Italian;
`server.py` serves the site locally:

```bash
python server.py
```
