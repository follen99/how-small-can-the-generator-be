Architettura RAG

Il nostro sistema RAG (Retrieval Augmented Generation) segue questa architettura:

  1. Document Ingestion: Parsing di PDF, DOCX, TXT con estrazione strutturata
  2. Chunking: Suddivisione in blocchi di 512-1024 token con overlap del 20%
  3. Embedding: Vectorizzazione con text-embedding-3-large (OpenAI) o BGE-large
  4. Vector Store: Storage in PostgreSQL pgvector con indice HNSW
  5. Retrieval: Hybrid search (semantico + BM25) con reranking
  6. Generation: Context injection in GPT-4o o Claude 3.5 Sonnet

Performance: Latenza media di 800ms per query complesse su knowledge base di 100k documenti.
